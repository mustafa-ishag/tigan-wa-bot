# 🤖 Tiqan WhatsApp Bot (إتقان)

بوت واتساب ذكي مخصص للرد التلقائي وإدارة الرسائل لنظام **إتقان**. يقوم البوت بالتواصل مع واجهات (APIs) نظام إتقان للرد على استعلامات أوامر العمل بشكل تلقائي وفوري.

---

## 🌟 المميزات

- 📩 **الرد التلقائي (Auto-Reply):** الرد فوراً على استعلامات أوامر العمل برسائل منسقة وجاهزة.
- 📡 **API مدمج:** إمكانية إرسال الرسائل عبر الـ API الخاص بالبوت برمجياً.
- 👥 **دعم المجموعات:** إمكانية قراءة وجلب المجموعات، وإرسال الرسائل للأفراد والمجموعات.
- 🎛️ **إدارة مرنة:** تشغيل وإيقاف ميزة الرد التلقائي بضغطة زر عبر نقطة اتصال (Endpoint) مخصصة.
- ⚙️ **متوافق مع الخوادم السحابية (VPS):** مصمم للعمل في الخلفية بكفاءة عالية على خوادم Ubuntu/Windows بدون تداخل مع البوتات الأخرى (تم ضبط البورت الافتراضي على **3001** لتجنب التعارض).

---

## 📋 المتطلبات

- نظام تشغيل Windows أو Linux (VPS).
- **Node.js** إصدار 18 أو أحدث.
- رقم واتساب لربط البوت (عبر مسح كود QR).

---

## 🚀 طريقة التثبيت والتشغيل على سيرفر VPS (بجانب بوت آخر)

بما أنك تستخدم هذا البوت في نفس السيرفر مع بوت آخر (مثل WhatsToot)، فقد تم ضبط هذا البوت ليعمل على المنفذ **3001** تجنباً للتعارض.

### 1. استنساخ المستودع
ادخل إلى مجلد المشروع وقم باستنساخ الكود:
```bash
cd /opt
sudo git clone https://github.com/mustafa-ishag/tigan-wa-bot.git
cd tigan-wa-bot
```

### 2. تثبيت الحزم المطلوبة
```bash
sudo npm install
```

### 3. إعداد البيئة ومتغيرات النظام
قم بنسخ ملف الإعدادات والتعديل عليه:
```bash
sudo cp .env.example .env
sudo nano .env
```
*(تأكد أن `PORT=3001` لكي لا يتعارض مع البوت الآخر الذي يعمل على 3000).*

### 4. إنشاء خدمة Systemd (ليعمل في الخلفية دائماً)
اكتب الأمر التالي لإنشاء ملف الخدمة:
```bash
sudo nano /etc/systemd/system/tiganbot.service
```
ثم انسخ هذا النص داخله (تأكد من تعديل المسارات إذا كانت مختلفة):
```ini
[Unit]
Description=Tiqan WhatsApp Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/tigan-wa-bot
ExecStart=/usr/bin/node /opt/tigan-wa-bot/server.js
Restart=always
RestartSec=10
Environment=NODE_ENV=production

[Install]
WantedBy=multi-user.target
```
احفظ الملف واخرج (Ctrl+X ثم Y ثم Enter).

### 5. تفعيل وتشغيل الخدمة
```bash
sudo systemctl daemon-reload
sudo systemctl enable tiganbot
sudo systemctl start tiganbot
```

### 6. مسح الـ QR Code (المصادقة)
الآن البوت يعمل في الخلفية ويحاول تسجيل الدخول، ستحتاج لفتح السجلات لمسح كود QR بجوالك:
```bash
sudo journalctl -u tiganbot -f
```
بمجرد مسح الباركود وظهور رسالة **"✅ تمت المصادقة بنجاح!"**، اضغط `Ctrl+C` للخروج من السجلات.

### 7. فتح البورت في الجدار الناري (Firewall)
للسماح للنظام الخارجي (PHP) بالتواصل مع البوت:
```bash
sudo ufw allow 3001/tcp
```

## 🌐 نقاط اتصال الـ API (Endpoints)

يستمع الخادم افتراضياً على المنفذ `3001`:

| المسار (Route) | النوع (Method) | الوصف |
|-----------------|----------------|-------|
| `/status` | `GET` | فحص حالة الخادم وتأكيد الربط مع واتساب. |
| `/groups` | `GET` | استرجاع قائمة بجميع المجموعات وصلاحياتها. |
| `/send-message` | `POST` | إرسال رسالة برمجياً إلى رقم شخصي أو مجموعة. |
| `/auto-reply/enable` | `POST` | تفعيل خاصية الرد التلقائي. |
| `/auto-reply/disable`| `POST` | إيقاف خاصية الرد التلقائي. |
| `/auto-reply/status` | `GET` | معرفة حالة الرد التلقائي الحالية. |

**مثال لإرسال رسالة (POST):**
```json
{
  "number": "966500000000",
  "message": "مرحباً! هذه رسالة تجريبية من نظام إتقان.",
  "isGroup": false
}
```
